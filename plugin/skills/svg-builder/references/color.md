## 順序ではなく意味をエンコードする

手順に沿って虹色を回さない。手順 1 が青、2 が琥珀、3 が赤だと、存在しない進行をほのめかし、読み手は
それを解読することに注意を使う。

代わりにカテゴリで割り当てる。

- **種類でまとめる。** 同じ種類のノードはすべて同じ色相。リクエストフローの図なら、クライアントは
  全部グレー、サービスは全部ティール、データストアは全部パープル。
- **説明図では色相を物理的な性質に対応させる。** 暖色（琥珀、コーラル、赤）は熱、エネルギー、圧力、
  重み大、活性。寒色（青、ティール）は冷たい、静か、休止。グレーは不活性な構造。ラベルを読まなくても
  *どこで何が起きているか*が見えるようにする。
- **中立にはグレー。** 開始、終了、汎用の手順、コンテナ、下地。

**色相 2 つとグレー。6 つは使わない。** グレー + ティール + コーラルの図は 9 つのランプを使った図より
読みやすく、この制約によって本当に異なるものが何かを決めざるを得なくなる。

青、緑、琥珀、赤には UI の強い慣習がある（情報、成功、警告、エラー）。それらの意味のために取っておき、
普通のカテゴリにはティール、パープル、コーラル、ピンクを使う。説明図は例外で、そこでは赤は「熱い」を
意味する。

## 既定のパレット

ランプ（1 つの色相の明暗の段階）ごとに 7 ストップ、明るい順。ユーザーからブランドカラーの指定がない

標準の割り当て:

- **ライトモード:** 塗り 50、枠線 600、タイトル 800、サブタイトル 600
- **ダークモード:** 塗り 800、枠線 200、タイトル 100、サブタイトル 200
- **コネクタとヘアライン:** グレーの 400（`#888780`）。白でもほぼ黒でも読めるので、モードの切り替え
  処理がまったく要らない
- **アクセントのマーク（点、アクティブ状態）:** アクセントのランプの 400

## 色付きの塗りの上の文字

塗りと**同じ系統**の最も濃いストップを使う。黒や汎用のグレーは使わない。どちらも色付きの背景の上では
描画ミスに見える。

箱にタイトルとサブタイトルの両方があるなら、**異なるストップ**を使う。ライトモードならタイトル 800、
サブタイトル 600（ダークなら 100 と 200）。同じストップだと、フォントウェイトを何にしても平板に見える。

```svg
<rect x="100" y="20" width="200" height="56" rx="8" fill="#E1F5EE"
      stroke="#0F6E56" stroke-width="0.5"/>
<text x="200" y="38" text-anchor="middle" dominant-baseline="central"
      fill="#085041" font-size="14" font-weight="500">Kafka producer</text>
<text x="200" y="56" text-anchor="middle" dominant-baseline="central"
      fill="#0F6E56" font-size="12">Batches and partitions</text>
```

## ダークモード: 戦略を 1 つ選ぶ

ユーザーが片方を除外しないかぎり両モードを前提にする。**半端な反転が最悪の結果**で、テーマに反応する
背景の上に固定の前景色を置くと、黒い背景に黒い文字になる。戦略を 1 つ選び、ファイル全体で貫く。

### 戦略 A — テーマ連動

すべての色をカスタムプロパティ経由にし、1 つのメディアクエリでプロパティを上書きする。図が UI に
近く、ページになじませたいときに使う。

```svg
<style>
  :root {
    --surface: #E1F5EE; --edge: #0F6E56; --ink: #085041; --hair: #888780;
  }
  @media (prefers-color-scheme: dark) {
    :root {
      --surface: #085041; --edge: #5DCAA5; --ink: #9FE1CB; --hair: #888780;
    }
  }
  .box  { fill: var(--surface); stroke: var(--edge); stroke-width: .5; }
  .t    { fill: var(--ink); font-size: 14px; font-weight: 500; }
  .ts   { fill: var(--ink); font-size: 12px; }
  .edge { fill: none; stroke: var(--hair); stroke-width: .5; }
</style>
```

注意: スタンドアロンの `.svg` ファイルの中の `prefers-color-scheme` は、ホストページのテーマ切り替え
ではなく*システム*の設定に従う。図をページの切り替えに追従させるなら、SVG を HTML にインライン化して
ページの変数をカスケードさせる。

### 戦略 B — モード非依存

白とほぼ黒の両方に対してコントラストを満たすランプ中程の値を選び、どちらのモードでも同じ見た目にする。
単純で失敗が少なく、物理的なリアリズムの場面では必須。反転した夕焼けは壊れている。

信頼できる中間ストップ: グレー `#888780`、ティール `#1D9E75`、パープル `#7F77DD`、コーラル `#D85A30`、
琥珀 `#EF9F27`。

**どちらの戦略でも頭の中で試す:** ページがほぼ黒だったら、すべての文字がまだ読めるか。覚えているもの
だけでなく、すべての `<text>` に対して確かめる。スタイルのない `<text>` は黒を継承して消える。

## コントラストの目標

| 要素 | 背景に対する比 |
|---|---|
| 本文とラベルの文字 | 4.5 : 1 |
| 大きな文字（18px 以上、または 14px 以上の太字） | 3 : 1 |
| 意味を持つストローク、アイコンの形、マーク | 3 : 1 |
| 装飾のヘアライン | 下限なし。ただし両モードで見えるようにする |

上の 400 ストップは白と `#0b0b0b` に対して 3:1 付近。ストロークやマークには十分だが、本文には
**不十分**。文字には、明るい塗りの上なら 600 以上、暗い塗りの上なら 100〜200 のストップが要る。

## 色だけに頼らない

男性の約 8% に色覚の特性があり、どんな図も印刷されたり、グレースケールの文書に貼られたり、フィルタ
越しにスクリーンショットされたりしうる。色相で担う区別には、すべて 2 つ目の手がかりを付ける。

- **破線パターン** — 副次的な経路は `stroke-dasharray="4 4"`、主経路は実線
- **線の太さ** — 既定 0.5px、強調する経路は 1.5px
- **形** — メッセージは円、バッチは四角、判断はひし形
- **疎なハッチングやドットのパターン**を `<pattern>` で、控えめに
- **対象そのものに直接ラベル**

赤と緑の組み合わせは最初から避ける。琥珀と青は一般的な色覚特性のすべてで区別できる。

グレースケールの検査: 選んだ塗りを輝度に変換する。2 つのカテゴリが約 10% 以内に収まるなら、読み手の
かなりの割合にとってそれらは同じ色である。

## ブランドのパレット

ユーザーがブランドカラーを渡してきたら、上の**構造**は保ったまま色相を差し替える。

1. 先方のプライマリをアクセントのランプに、ニュートラルをグレーに対応させる。
2. 必要なストップを導出する。塗りは白に向けて明るく、文字は黒に向けて暗く。色相ごとに最低でも、
   明るい塗り、中間の枠線、濃い文字の 3 ストップが要る。
3. 導出した文字のストップをその塗りに対して 4.5:1 で確認する。ブランドのパレットは大きなマーク向けに
   調整されており、12px ではしばしば落第する。
4. パレットに色が 1 つしかないなら、アクセントのカテゴリにそれを使い、残りはすべてグレーにする。
   ニュートラルの上に 1 つのブランド色は意図的に見えるが、6 カテゴリに引き伸ばしたブランド色は壊れて
   見える。
