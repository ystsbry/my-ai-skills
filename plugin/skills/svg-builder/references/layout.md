## キャンバスとセーフエリア

既定のキャンバスは `viewBox="0 0 680 H"` に `width="100%"`。内容は `x: 40..640` に置く。使えるのは
600px。両側 40px の余白が、引き出し線、外側のラベル、矢印の先を吸収する。

**内容が狭くても幅は 680 のままにする。** `width="100%"` は座標空間全体をコンテナに合わせて拡大する。
680px のコンテナで幅 476 の viewBox を使うと全体が 1.43 倍になり、14px の文字が 20px で描画され、
以下の幅の計算がすべて黙って狂う。狭い内容は 680 の中で中央に寄せる。

680 を変えるのはユーザーが目標の幅を指定したときだけ。そのときはセーフエリアの 600 も一緒に変える。

## 文字幅

SVG の `<text>` は折り返さず、文書に置かれるまで自分の幅を報告しない。配置する前に見積もる。

| フォントサイズ | ウェイト | 1 文字あたりの概算 px |
|---|---|---|
| 14px | 400 | 8 |
| 14px | 500 | 8.5 |
| 12px | 400 | 7 |
| 11px | 400 | 6.5 |

実測した較正点:

```
"Authentication Service"     22 文字, 500, 14px  →  167px
"Background Job Processor"   24 文字, 500, 14px  →  201px
"Detects and validates …"    37 文字, 400, 14px  →  279px
"forwards request to"        19 文字, 400, 12px  →  123px
"データベースサーバー接続"        12 文字, 400, 14px  →  181px
```

**最も長いラベルから箱の幅を決める:**

```
box_width ≥ max(title_chars × 8, subtitle_chars × 7) + 24
```

100px の箱に入るのは 10 文字のサブタイトルまでで、それ以上は入らない。

**幅広グリフの倍率。** 化学式（C₆H₁₂O₆）、数学記号（∑ ∫ √）、上付き・下付き、日本語・中国語・韓国語
（CJK）には 30〜50% 上乗せする。上の例では CJK 12 文字が、ラテン文字 22 文字分の幅を占めている。
日本語のラベルは 1 文字あたり約 15px（14px、ウェイト 400 の実測）で見積もる。バリデータも CJK
1 文字をラテン文字 1.8 文字分として数える。下付きの数字も横幅はフルに取る。

**`text-anchor` で文字列が伸びる向きが決まる:**

| アンカー | 占める範囲 | リスク |
|---|---|---|
| `start` | `x` から `x + width` | 右端からはみ出す |
| `middle` | `x ± width/2` | 両側にはみ出す |
| `end` | `x − width` から `x` | **負の x へはみ出す** |

黙って見切れるのは `text-anchor="end"`。`x=60` に 200px のラベルを置くと `x=−140` から始まり、
最初の 3 分の 2 は描画されない。`chars × 8 < x` を確認するか、代わりに `text-anchor="start"` で
列を右寄せにする。

## 縦の配置

SVG は `y` を中心ではなく**ベースライン**として扱う。箱の算術的な中心に置いたラベルは約 4px 浮き、
ディセンダ（g, p, y, q）が下にあるものとぶつかる。

常に:

```svg
<text x="190" y="42" text-anchor="middle" dominant-baseline="central">T-cells</text>
```

`(x, y, w, h)` の箱にラベルが 1 つなら `text_x = x + w/2`、`text_y = y + h/2`。

行が複数ある箱では、`y` は箱ではなく**その行**の中心。`y=20` にある高さ 56px の 2 行の箱なら、
タイトルは `y=38`、サブタイトルは `y=56`。18px 離し、それぞれ 28px の半分の中央に置く。

標準の箱の高さ: 1 行なら **44px**、2 行なら **56px**。同じ種類の内容を持つ段の箱はすべて同じ高さに
する。高さが不揃いだと間違いに見える。

## 段の詰め方

`n` 個の箱を 1 行に置く前に:

```
n · width + (n−1) · gap ≤ 600
```

| n | 間隔 20px での最大幅 |
|---|---|
| 2 | 290 |
| 3 | 186 |
| 4 | 135 |
| 5 | 104 |
| 6 | 83 — ラベルには狭すぎる。折り返すか分割する |

失敗例と修正:

```
誤  箱 4 個 w=160 を x=40,200,360,520 に   → 4·160+3·20 = 700 > 600、箱が重なる
正  箱 4 個 w=130 を x=50,200,350,500 に   → 4·130+3·20 = 580 ≤ 600、右端 630 ✓
```

幅 `w` の箱 `n` 個をセーフエリアに等間隔で置く x 座標:

```
gap   = (600 − n·w) / (n − 1)
x[i]  = 40 + i · (w + gap)
```

箱 `i` の中心は `x[i] + w/2`。その箱に触れるすべてのコネクタのアンカーになる。

1 段に 6 個以上になったら詰めるのをやめて設計を変える。2 行に折り返す、110px 以下に縮めて
サブタイトルを落とす、全体図と詳細図に分割する。

## ツリーと階層

**下から上へ**サイズを決める。葉がすべてを決める。

1. 葉の段を上の詰め方の式で配置する。
2. 親の中心は子の中心の平均。
3. 親の幅は自分のラベルの幅以上、子の広がりより広くはしない。
4. 手順 2 のあとで 2 つの親の広がりが重なるなら、葉の段が詰まりすぎている。間隔を広げるか葉を減らす。

縦のリズム: 段の間は最低 40px、コネクタにラベルが付くなら 60px。

## エッジの配線

**配置済みのすべての rect に対して、すべての線を突き合わせてから**書く。A から B への線が C の内部を
通ると、目に見えて C を横切る。ブラウザは警告しない。

端点が揃っているなら垂直または水平の直線:

```svg
<line x1="200" y1="76" x2="200" y2="120" stroke="#888780" stroke-width="0.5"
      marker-end="url(#arrow)"/>
```

揃っていないとき、または直線が何かを横切るときは L 字の折れ線:

```svg
<path d="M120 76 L120 100 L340 100 L340 132" fill="none" stroke="#888780"
      stroke-width="0.5" marker-end="url(#arrow)"/>
```

コネクタの path には `fill="none"` が必須。ないと path が閉じて黒く塗りつぶされる。

**ファンインとファンアウト**（複数の送り元が 1 つの送り先に集まる）: 各送り元を段の間の y にある
共有の横線（バス）まで下ろし、バスを走らせ、送り先へ 1 本だけ下ろす。N 本の斜線よりはるかに綺麗で、
バスは箱を横切らない。

```svg
<path d="M160 84 V108 H520" fill="none" stroke="#888780" stroke-width="0.5"/>
<path d="M340 84 V108"      fill="none" stroke="#888780" stroke-width="0.5"/>
<path d="M340 108 V132"     fill="none" stroke="#888780" stroke-width="0.5"
      marker-end="url(#arrow)"/>
```

**矢印の先と送り先の縁の間は 10px 空ける。** 触れているのではなく、箱を指しているように読める。

**直線的なフローの中の戻りのエッジ**は流れの向きに逆らい、キャンバスの端で見切れる。長い矢印を図の
反対側まで引き回す代わりに、ループ地点の近くに `↻` の記号と短いラベルを置く。

**矢印の上のラベルはたいてい悪い兆候。** エッジの意味が送り元と送り先から明らかでないなら、送り元と
送り先を直す。本当にラベルが必要なら、線の脇の空いた場所に置く。線の中点には置かない。ストロークと
ぶつかる。

## viewBox の高さ

```
max_y  = 全要素の最大値:
           rect:   y + height
           circle: cy + r
           text:   y + 4          （ベースラインの下のディセンダ）
           path:   d 属性の中で最大の y
viewBox_height = max_y + 20
```

どちら向きもバグである。小さすぎれば最下段が見切れ、大きすぎれば余白が残って図がコンテナの中で浮く。
バリデータは両方を指摘する。

## 複数行のラベル

自動の折り返しはない。各行を明示的な `tspan` にする:

```svg
<text class="ts" x="200" y="120" text-anchor="middle">
  <tspan x="200">Validates the token</tspan>
  <tspan x="200" dy="1.2em">and refreshes it</tspan>
</text>
```

すべての `tspan` で `x` を繰り返す。省くと、前の行が終わった位置から次の行が始まる。

予算: 12px で `1.2em` は 1 行あたり約 14px。2 行のサブタイトルは 1 行のものより箱の高さが 14px
多く要る。

**2 行目に手を伸ばす前に、ラベルを削る。** 5 語を超えるサブタイトルはほぼ例外なく、箱の中ではなく
図の脇の文章に属する文である。
